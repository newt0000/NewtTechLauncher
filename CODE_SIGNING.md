# Code signing policy

Official Windows releases of NewtTech Launcher are built from
the public NewtTech Launcher source repository.

Free code signing provided by SignPath.io,
certificate by SignPath Foundation.

## Team roles

Committer and reviewer:
- Newt_00

Approver:
- Newt_00

## Privacy

NewtTech Launcher communicates with launcher.newttech.net to retrieve
launcher updates, modpack metadata, modpack files, and required game
version files.

The application does not transmit personal information to other
networked systems unless required for functionality explicitly
requested by the user.

## Release signing

Only official release builds produced from this repository are
submitted for signing.

Third-party binaries and libraries are not signed as NewtTech
Launcher components.

## Installation

NewtTech Launcher provides an installer and an uninstall facility.
